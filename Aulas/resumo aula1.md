# Aula 01 - Apresentação da Disciplina e Contextualização

## Objetivo da Aula

A primeira aula apresentou a disciplina de **Frameworks Front-end**, abordando o plano de ensino, os conteúdos que serão estudados durante o semestre, a metodologia de ensino, os critérios de avaliação e a importância do desenvolvimento Front-end no mercado de tecnologia.

---

## O que é Front-end?

O Front-end é a camada de uma aplicação responsável pela interação entre o usuário e o sistema. Seu objetivo é desenvolver interfaces modernas, intuitivas e funcionais, proporcionando uma boa experiência ao usuário (UX), além de realizar a comunicação com os serviços responsáveis pelo processamento dos dados.

---

## Importância dos Frameworks Front-end

Atualmente, a maioria das aplicações web utiliza frameworks Front-end para tornar o desenvolvimento mais organizado, reutilizável e de fácil manutenção. Esses frameworks permitem criar interfaces mais rápidas, escaláveis e eficientes, atendendo às necessidades das empresas modernas.

Durante a disciplina serão apresentados os principais frameworks utilizados no mercado:

- React
- Vue.js
- Angular

Além de conceitos como:

- Componentização
- Gerenciamento de estado
- Rotas
- Integração com APIs

---

## Desenvolvimento Web

Também foram apresentados conceitos importantes para o desenvolvimento de aplicações web, incluindo:

- UX (Experiência do Usuário)
- UI (Interface do Usuário)
- Prototipação
- Validação de ideias
- Arquitetura de aplicações
- Versionamento de código
- Deploy de aplicações

---

## JavaScript

A disciplina inicia utilizando **JavaScript puro (Vanilla JS)**, que serve como base para compreender o funcionamento dos frameworks modernos.

O JavaScript é responsável por adicionar lógica às páginas web, manipular elementos da interface e realizar comunicação com servidores.

---

## Objetivos da Disciplina

Ao final do semestre, espera-se que o aluno seja capaz de:

- Desenvolver interfaces modernas;
- Criar aplicações utilizando Frameworks Front-end;
- Utilizar Git e GitHub para versionamento;
- Publicar aplicações na Web (Deploy).

---

## Metodologia

A disciplina será conduzida por meio de:

- Aulas expositivas;
- Discussões em sala;
- Estudos de caso;
- Desenvolvimento de projetos práticos;
- Integração entre teoria e prática.

---

## Avaliação

A avaliação será composta por:

- **55%** – Avaliação Docente
  - **20%** – Desenvolvimento do Projeto
  - **20%** – Apresentação do Projeto
  - **15%** – Realização das atividades

- **35%** – Projeto Integrador

- **10%** – Autoavaliação

---

## Projeto da Disciplina

Durante o semestre será desenvolvido um projeto completo, desde o planejamento até a entrega final. O projeto deverá conter documentação detalhada, organização do backlog, benchmarking e apresentação dos resultados obtidos.

---

## Atividade Inicial

Como primeira atividade da disciplina, os grupos deverão:

1. Formar equipes de **3 a 5 integrantes**;
2. Criar um repositório no **GitHub**;
3. Elaborar um arquivo **README.md** contendo um resumo da Aula 01;
4. Produzir um relatório técnico sobre um Framework Front-end escolhido pelo grupo.

---

# Conclusão

A Aula 01 apresentou a estrutura da disciplina de Frameworks Front-end e contextualizou sua importância no desenvolvimento web moderno. Também foram apresentados o plano de ensino, a metodologia, os critérios de avaliação e as atividades que serão desenvolvidas ao longo do semestre, preparando os alunos para criar aplicações modernas utilizando boas práticas, Git/GitHub e frameworks amplamente utilizados pelo mercado.
