# Aula 06 - Projetos Front-end

## Objetivo da Aula

Esta aula apresentou conceitos de gestão aplicados ao desenvolvimento Front-end. O objetivo foi aprender a organizar requisitos, tarefas, prioridades e entregas de forma colaborativa, utilizando práticas ágeis e ferramentas de versionamento.

---

## Gestão de Projetos Front-end

Gerenciar um projeto Front-end significa organizar pessoas, tarefas, tecnologias e prazos para transformar uma ideia em uma aplicação funcional.

Sem planejamento, projetos podem apresentar:

- tarefas esquecidas;
- requisitos confusos;
- retrabalho;
- atrasos;
- conflitos no Git;
- dificuldades de integração;
- pouca visibilidade sobre o andamento.

## Gestão de Requisitos

A partir de uma ideia, o projeto deve definir requisitos claros. Esses requisitos podem ser detalhados em histórias de usuário e divididos em tarefas menores.

Exemplo:

- **Requisito:** o sistema deve permitir gerenciar tarefas;
- **User Story:** como usuário, quero criar uma tarefa;
- **Tarefas:** criar formulário, criar componente, validar campos, integrar API e testar.

## Backlog

O backlog é uma lista organizada de funcionalidades, melhorias, correções e atividades necessárias ao projeto. Os itens podem ser priorizados para que a equipe desenvolva primeiro os requisitos mais importantes.

## Prioridade e Estimativa

A priorização ajuda a decidir quais funcionalidades devem ser desenvolvidas primeiro. As estimativas ajudam a equipe a compreender a complexidade relativa das atividades e planejar o trabalho.

## Definition of Done

A Definition of Done define os critérios necessários para considerar uma tarefa concluída. Podem fazer parte desses critérios:

- código implementado;
- testes realizados;
- código revisado;
- responsividade verificada;
- integração concluída;
- documentação atualizada;
- alterações enviadas ao repositório.

## Scrum

Scrum é um framework ágil que organiza o desenvolvimento em ciclos incrementais chamados Sprints. Ele permite inspecionar os resultados com frequência e adaptar o planejamento durante o projeto.

No desenvolvimento Front-end, o Scrum pode ajudar a:

- organizar requisitos;
- priorizar funcionalidades;
- planejar Sprints;
- acompanhar o progresso;
- realizar entregas contínuas;
- identificar impedimentos.

## Organizando o Projeto Integrador

A atividade prática deve utilizar conceitos de gestão para criar:

- backlog;
- prioridades;
- tarefas;
- estimativas;
- Sprint;
- quadro Kanban;
- branches;
- critérios de conclusão;
- documentação do processo.

## Conclusão

A gestão transforma ideias em entregas organizadas e mensuráveis. Requisitos bem definidos, backlog priorizado, estimativas e critérios de conclusão ajudam equipes a reduzir retrabalho e acompanhar a evolução do projeto integrador.
